# Data Overview

## Raw Data

This folder contains sample raw datasets used in the ETL pipeline.

- mortality_records_sample.csv
- maid_procedures_sample.csv

These datasets include common data quality issues such as:
- inconsistent province naming
- missing values
- duplicate records
- mixed data types

## Processed Data

- maid_final_sample.csv

This file represents the final output of the ETL pipeline after:
- cleaning and standardization
- validation
- joining datasets
- deriving reporting metrics
